Go 学习：结构体、方法与包

发表于2026-11-18|更新于2026-11-27|编程学习
|阅读量:

当天完成 Go 第一阶段第 10～12 课：结构体、方法与接收者、包与模块。共完成 15 道练习，其中答对 13 道。

把相关数据放进结构体

用 type Cat struct { ... } 定义图纸，再用 Cat{Name: "咪咪", Age: 3} 创建实例。字段名区分大小写；带字段名的字面量不依赖字段顺序。

方法的接收者决定能否改原值

func (c Cat) Say() string 中的 c 是副本，适合读取数据。要修改外部的结构体，用指针接收者：

调用 c.Grow() 时，Go 会在可取地址的情况下自动传入 &c。

包是文件夹，模块是项目根

同一文件夹内的 Go 文件必须使用同一个 package 名。跨文件夹使用代码要靠 import，名称是否能被外部包使用取决于首字母是否大写。

当天还记录了 fmt.Printf("%+v\n", c)：%+v 会在打印结构体时同时显示字段名，便于检查数据。
